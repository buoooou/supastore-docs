SupaStore 兼容经典的 OpenAI Completions 纯文本补全接口。

> [!NOTE]
> 绝大多数现代对话模型（如 `gpt-4o` / `claude-3-5-sonnet`）均已转向结构更清晰的 [聊天对话 (Chat completions)](/api-chat) 接口。除非您必须使用 `gpt-3.5-turbo-instruct` 等纯续写模型，否则建议优先选择聊天接口。

### 📡 接口信息

* **请求方式**: `POST`
* **接口路径**: `/v1/completions`
* **Content-Type**: `application/json`

---

## 📦 请求参数 (Request Body)

| 参数名 | 类型 | 必填 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| **model** | string | 是 | - | 使用的续写补全模型，如 `gpt-3.5-turbo-instruct`。 |
| **prompt** | string/array | 是 | `&lt;|endoftext|&gt;` | 引导续写的基础提示词。可以是单个字符串或字符串数组。 |
| **max_tokens** | integer | 否 | `16` | 允许生成的最大 Token 数量。 |
| **temperature** | number | 否 | `1.0` | 采样温度。 |
| **stream** | boolean | 否 | `false` | 是否启用流式打字输出。 |

---

## 💻 调用示例 (cURL)

```bash
curl -X POST "https://supastore.cc/v1/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-3.5-turbo-instruct",
    "prompt": "在很久很久以前，有一座神秘的森林，里面住着",
    "max_tokens": 50,
    "temperature": 0.6
  }'
```
