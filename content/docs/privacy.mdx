在 **SupaStore**，我们深知数据隐私对于开发者和企业用户的重要性。本隐私政策旨在透明地向您说明我们在您调用 AI 模型接口及访问控制面板时，如何收集、处理和保护您的数据。

---

## 1. 核心承诺：不记录、不缓存对话内容 (Zero Payload Logging)

作为 AI 中转转发网关，我们坚持数据中立原则。**SupaStore 承诺绝不持久化存储或共享您的以下数据：**
- **提示词与补全内容 (Prompt & Completion)**：所有流式 (Stream) 或非流式 API 对话请求的输入与输出 Payload，均仅在内存中进行中转和转发，网络连接断开后立即释放，绝不在任何持久化介质（如数据库、本地日志文件）中留存。
- **多模态输入文件**：您通过 API 传输的图像、语音、视频等二进制数据直接流式传输给上游 API，本站不进行任何缓存或存储。
- **自定义敏感元数据**：我们不解析、不存储您请求头中携带的自定义组织 ID 或最终用户标识。

---

## 2. 我们收集的必要数据

为了进行计费结算、配额校验及提供技术支持，我们仅收集以下最小限度的必要信息：

- **账户基本信息**：您注册账户时提供的电子邮件地址。用于身份识别、密码重置及账单、安全通知的发送。
- **API 消费计量数据**：
  - 调用时间与使用的模型 ID（如 `claude-3-5-sonnet-latest`）。
  - 消耗的 Token 数量（输入 Prompt Tokens、推理 Reasoning Tokens、输出 Completion Tokens）。
  - 该次调用的计费金额与扣费状态。
- **API 状态码与基本日志**：
  - 调用的 HTTP 状态码（如 `200`、`429`、`500`）。
  - 用于故障排查的请求延迟 (Latency) 统计，以及由上游服务返回的脱敏错误代码（如 `insufficient_quota`）。
- **充值交易记录**：我们通过第三方支付平台处理充值。我们不记录亦无法获取您的信用卡号或详细银行账户信息，仅记录支付通道返回的交易流水号和金额。

---

## 3. 信息安全防护

我们采用多重安全机制，确保您的 API Key 和数据传输万无一失：
- **全链路加密**：API 接口与用户后台均采用最高级别的 TLS/HTTPS 加密传输，防止数据在传输过程中被窃听或篡改。
- **密钥哈希与隔离**：您生成的 API Key 在数据库中采用单向高强度加密存储。我们建议您为不同的项目或客户端（如 Cursor、Dify 等）分别创建专用的 API Key，并随时根据需要撤销或限额。
- **严格权限控制**：我们的运维团队无权、也无法在系统运行中拦截或查看您的具体 API 交互内容。

---

## 4. 您的权利

您可以通过控制面板随时行使以下权利：
- **查看与修改**：查看您的账户消费明细、账单记录并修改邮箱或密码。
- **注销账户**：如果您不再需要我们的服务，可随时申请注销账户。账户注销后，我们将在 30 天内清除数据库中您的所有个人信息与关联 API Key。
