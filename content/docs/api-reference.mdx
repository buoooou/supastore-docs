SupaStore 提供标准的 RESTful API 接口，全面兼容主流 AI 模型。通过统一的 API 格式和 Base URL，您可以零门槛地将最新 AGI 能力接入您的智能应用、编辑器插件或自研开发流中。

---

## 🛠️ API 端点 (Base URL)

SupaStore 为开发者提供专用的高可用 API 网关端点：

```http
https://api.supastore.cc/v1
```

> [!NOTE]
> 如果您是在 Cursor、Cline、LobeChat 等客户端中进行配置，请在 **Base URL / API 地址** 栏填写 `https://api.supastore.cc/v1` 或 `https://api.supastore.cc`（部分客户端会自动追加 `/v1`，建议根据提示配置）。

---

## 🔑 身份认证 (Authorization)

所有 API 请求均须通过 HTTP Header 进行身份验证。您需要在 HTTP 请求头中附加 Bearer Token：

```http
Authorization: Bearer YOUR_SUPASTORE_API_KEY
```

您可以登录 [SupaStore 控制台](https://supastore.cc/console) 在 **API Keys** 菜单中生成并管理您的密钥。

> [!WARNING]
> API 密钥 (API Key) 是您额度抵扣的唯一凭证，请勿在前端代码中暴露，或将其泄露给未经信任的第三方。

## ⚡ 最小可用请求

如果您只想确认 API Key 是否可用，可以直接运行下面的 cURL：

```bash
curl "https://api.supastore.cc/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SUPASTORE_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "请回复 pong"}
    ]
  }'
```

Node.js 示例：

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.SUPASTORE_API_KEY,
  baseURL: "https://api.supastore.cc/v1"
});

const completion = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "请回复 pong" }]
});

console.log(completion.choices[0]?.message?.content);
```

Python 示例：

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["SUPASTORE_API_KEY"],
    base_url="https://api.supastore.cc/v1",
)

completion = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "请回复 pong"}],
)

print(completion.choices[0].message.content)
```

## 常见错误码

| HTTP 状态码 | 常见原因 | 处理建议 |
| :--- | :--- | :--- |
| `400` | 请求体格式错误、参数缺失、模型 ID 不存在 | 检查 JSON、`model`、`messages` 等必填字段。 |
| `401` | API Key 缺失或错误 | 确认 Header 为 `Authorization: Bearer YOUR_SUPASTORE_API_KEY`。 |
| `402` | 账户余额不足 | 前往 [充值中心](https://supastore.cc/console/topup) 补充额度。 |
| `429` | 请求过于频繁或超过并发限制 | 降低客户端并发、增加重试退避，或升级套餐。 |
| `500` | 网关或上游模型临时异常 | 稍后重试；生产服务建议配置指数退避与备用模型。 |
