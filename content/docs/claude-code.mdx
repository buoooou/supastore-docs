[Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview) 是 Anthropic 官方推出的命令行交互式 AI 编程代理工具。它不仅能够直接读取和写入您的本地文件，还能够执行终端命令、分析 Git 提交、搜索代码库等。

通过 SupaStore 中转，您可以在没有 Anthropic Console 官方开发者账号或未绑定外卡的情况下，使用 SupaStore 的 API 密钥和接口直接启动并运行 Claude Code。

---

## 📦 安装 Claude Code

### Windows

<Steps>

<Step>第一步：安装 Node.js 环境</Step>

Claude Code 需要 Node.js 环境才能运行。

1. 打开浏览器访问 [https://nodejs.org/](https://nodejs.org/)，下载 **LTS** 版本。
2. 双击 `.msi` 文件，按照安装向导完成安装，保持默认设置即可。
3. 安装完成后，打开 PowerShell，验证安装：
   ```powershell
   node --version
   npm --version
   ```

> [!TIP]
> 建议使用 PowerShell 而不是 CMD。如果遇到权限问题，尝试以管理员身份运行。

<Step>第二步：安装 Git Bash</Step>

Windows 环境下需要使用 Git Bash 来安装 Claude Code（安装完成后仍然在 PowerShell 中使用）。

1. 访问 [https://git-scm.com/downloads/win](https://git-scm.com/downloads/win) 下载安装包。
2. 运行安装文件，保持默认设置一路 Next 完成安装。

<Step>第三步：安装 Claude Code</Step>

打开 PowerShell，运行：

```powershell
npm install -g @anthropic-ai/claude-code
```

如果提示需要将 `~/.local/bin` 加入 PATH：

```powershell
[Environment]::SetEnvironmentVariable('Path', ([Environment]::GetEnvironmentVariable('Path','User') + ";$HOME\.local\bin"), 'User')
```

验证安装：

```powershell
claude --version
```

</Steps>

### macOS

<Steps>

<Step>第一步：安装 Claude Code CLI</Step>

打开终端，运行官方安装脚本：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

如果提示需要配置 PATH：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

验证安装：

```bash
claude --version
```

</Steps>

### Linux

<Steps>

<Step>第一步：安装 Claude Code</Step>

打开终端，运行：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

如果遇到权限问题：

```bash
sudo curl -fsSL https://claude.ai/install.sh | bash
```

验证安装：

```bash
claude --version
```

</Steps>

## 🛠️ 配置接入 SupaStore

安装完成后，需要将 Claude Code 的 API 流量指向 SupaStore。主要有两种方式：

### 方式一：修改配置文件 `settings.json` (推荐)

这是最稳定的持久化配置方案。即使重启终端或电脑，配置也会一直保留。

1. 编辑或新增 Claude Code 配置文件 `~/.claude/settings.json`（在 Windows 上通常位于 `C:\Users\您的用户名\.claude\settings.json`）。
2. 在 JSON 配置的 `env` 字段中，增加 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`。

配置文件内容示例如下：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "您的SupaStore_API_KEY",
    "ANTHROPIC_BASE_URL": "https://api.supastore.cc/v1",
    "API_TIMEOUT_MS": "300000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}
```

> [!IMPORTANT]
> - 请注意将上面的 `"您的SupaStore_API_KEY"` 替换为您在 SupaStore 控制台获取的以 `sk-` 开头的真实密钥。
> - `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` 设为 `"1"` 可以禁止非必要的遥测流量，节省 Token 消耗。
> - 配置保存后，在命令行中直接运行 `claude` 即可自动读取该配置启动服务。

---

### 方式二：使用环境变量 (临时/快速测试)

如果您只是想快速体验或在一台临时服务器上运行，可以直接在启动命令前配置环境变量。

#### macOS / Linux 终端配置：
```bash
export ANTHROPIC_BASE_URL="https://api.supastore.cc/v1"
export ANTHROPIC_AUTH_TOKEN="YOUR_SUPASTORE_API_KEY"

# 启动 Claude Code
claude
```

#### Windows PowerShell 终端配置：
```powershell
$env:ANTHROPIC_BASE_URL="https://api.supastore.cc/v1"
$env:ANTHROPIC_AUTH_TOKEN="YOUR_SUPASTORE_API_KEY"

# 启动 Claude Code
claude
```

> [!NOTE]
> 设置环境变量后，使用所有模型（包括官方预设模型）均通过 SupaStore 接入点调用，不会使用官方账号额度。

## 🚀 启动与使用示例

当您成功配置并启动 `claude` 后，Claude Code 会扫描您的当前项目，并进入一个交互式的 Shell 命令行界面。

在特定项目中使用：

```bash
# 进入你的项目目录
cd /path/to/your/project

# 启动 Claude Code
claude
```

### 切换模型

在 Claude Code 交互界面中输入 `/model` 命令，按 Enter 即可选择不同的模型。通常使用默认模型即可。

### 自然语言交互示例

* **代码解析与问答**：
  ```bash
  > 这个项目是用什么技术栈写的？入口文件在哪里？
  ```
* **自动生成与编辑文件**：
  ```bash
  > 请帮我在 components 目录下新建一个 button.tsx 组件，需要包含 tailwind 的幽灵按钮样式。
  ```
* **诊断与排障**：
  ```bash
  > 为什么我运行 npm run build 会报错，请读取报错信息并帮我修复。
  ```

## ⚡ 性能调优建议

由于 Claude Code 在运行期间可能会对您的代码库进行高频次的检索与多步骤推理（会产生巨大的 Context Tokens），我们建议：

1. **账户余额充足**：使用前确保您的 **[充值钱包](https://supastore.cc/console/topup)** 有足够余额，防止由于中途欠费导致多步骤任务被异常中断。
2. **过滤多余文件**：在项目根目录下配置 `.gitignore` 或 `.claudeignore`，排除如 `node_modules`、`.next`、`dist` 等构建产物和临时缓存文件夹，以大幅减少 Token 的消耗并提升响应速度。

## 🔧 常见问题与排障

### macOS 安全设置阻止运行

如果系统阻止运行 Claude Code：

1. 打开 **系统偏好设置** → **安全性与隐私**。
2. 点击 **"仍要打开"** 或 **"允许"**。
3. 或者在终端中运行：
   ```bash
   sudo spctl --master-disable
   ```

### Linux 缺少依赖库

某些 Linux 发行版需要安装额外依赖：

```bash
# Ubuntu/Debian
sudo apt install build-essential

# CentOS/RHEL
sudo dnf groupinstall "Development Tools"
```

### 环境变量不生效

请检查以下几点：

- 确认修改了正确的配置文件（`.bashrc` 或 `.zshrc`）。
- 重新启动终端或运行 `source ~/.bashrc`（或 `source ~/.zshrc`）。
- 验证设置：`echo $ANTHROPIC_BASE_URL`。

### 提示 "Invalid API Key" 或 "Authentication Failed"

- 请确认您的 SupaStore 密钥没有复制多余的空格，且开头为 `sk-`。
- 确认您的 **[钱包余额](https://supastore.cc/console/topup)** 是否充足，如果钱包额度为 0，请求会被拒绝。
