## SupaStore 服务与 API 使用许可

本使用许可协议规定了您访问和使用 **SupaStore** 大模型 API 接口、开发者控制台以及平台相关脚手架工具的权利。

---

## 1. 许可的授予

- 在您遵守本协议条款的前提下，SupaStore 授予您一项有限的、不可转让的、非排他性的、可撤销的许可，以接入我们的 API 接口并将其集成到您的应用或开发环境中（如 Cursor、Claude Code、以及您的自研软件项目）。
- 本许可的使用限度（如调用额度、最大并发连接数）由您账户中充值的代币余额及平台设定的限速规则决定。

---

## 2. 使用许可限制

以下行为超出了本协议授予的许可范围，将导致许可自动终止：
- 尝试通过逆向工程、反编译或破解手段窃取平台网关程序或计费系统的核心源代码。
- 将您的 SupaStore 账户控制台主账号转让或租借给无关的第三方。
- 通过漏洞利用、绕过网关防护等方式无偿套取 API 调用额度。

---

## 3. 费用与结算

- 您需要为通过您的 API Key 发起的所有模型请求支付对应 Token 的费用。费用标准以 [模型价格页](https://api.supastore.cc/pricing) 为准。
- 所有计费均由本平台的网关自动进行审计和扣减。

---

## 4. 终止

如果您违反了本许可协议或平台的 [服务条款](/terms)，我们保留随时暂停或彻底注销您 API Key 的权利，该操作将导致您失去通过我们网关调用大模型的能力。

---

## 5. 协议接受

注册 SupaStore 账户或生成首个 API Key 即表示您已阅读并完全接受本许可协议的全部内容。如有任何疑问，请联系我们：[support@supastore.cc](mailto:support@supastore.cc)
