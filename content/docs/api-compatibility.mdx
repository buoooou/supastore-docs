## 🛠️ 请求地址与格式

* **API Base URL**: `https://api.supastore.cc/v1`
* **认证方式**: 在 HTTP Headers 中加入 Bearer Token:
  `Authorization: Bearer YOUR_SUPASTORE_API_KEY`

---

## 💻 基础测试：cURL 请求示例

在使用客户端配置前，您可以在终端中运行以下 cURL 命令以验证您的 API 密钥和接口通信：

```bash
curl https://api.supastore.cc/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SUPASTORE_API_KEY" \
  -d '{
    "model": "claude-3-5-sonnet-latest",
    "messages": [
      {"role": "user", "content": "你好，请确认你的模型名称并说一句打招呼的话。"}
    ],
    "temperature": 0.7
  }'
```

若接口返回正常的 JSON 格式响应（类似下面所示），说明网络连接与密钥鉴权均完全正常：

```json
{
  "id": "chatcmpl-xxxxx",
  "object": "chat.completion",
  "created": 1716666666,
  "model": "claude-3-5-sonnet-latest",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "你好！我是 Claude 3.5 Sonnet。很高兴通过 SupaStore 与您建立连接！"
      },
      "finish_reason": "stop"
    }
  ]
}
```
