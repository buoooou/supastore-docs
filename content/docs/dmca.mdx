**SupaStore** 作为中立的 AI 大模型 API 中转转发服务提供商，尊重知识产权，并坚决反对利用 AI 技术从事恶意滥用或侵权行为。本页面说明了我们如何处理针对接口调用的滥用投诉及 DMCA 请求。

---

## 1. 滥用定义与范围

以下行为均被视为对 SupaStore API 的恶意滥用：
- **恶意钓鱼与垃圾内容**：利用 API 自动化生成大批垃圾邮件文本、钓鱼网站文案或实施社交媒体机器人欺诈。
- **爬虫与越权数据收集**：利用本站代理网络对目标网站进行高强度的分布式抓取。
- **版权侵权生成**：诱导多模态大模型生成或修改与他人享有完全版权的注册商标、受版权保护的艺术作品完全一致的侵权内容。

---

## 2. 滥用调查与处置流程

当我们收到来自上游供应商、云服务提供商或版权所有者的滥用投诉后，将按以下步骤处理：
- **初步核实**：安全运维团队将根据投诉提供的 IP 地址、时间戳及 API Key 标识进行检索定位。
- **警告与限制**：对于首次发生的轻度滥用（如并发数异常偏高导致上游报警），我们将邮件通知用户限期整改，并可能临时调低该账户的并发限速。
- **立即封禁**：涉及版权侵权生成、恶意网络攻击或欺诈的，我们将直接吊销涉事 API Key 乃至封禁账户，且不支持退款。

---

## 3. 如何提交滥用投诉

如果您发现有源自 SupaStore 网关或利用本站接口实施的恶意侵权活动，请向我们提交投诉：
- **接收邮箱**：[abuse@supastore.cc](mailto:abuse@supastore.cc)
- **投诉格式**：邮件主题请使用 `Abuse Report - [类型描述]`。
- **必要证明信息**：请提供被侵权作品的版权证书或原作者链接、侵权内容在 SupaStore 代理下生成的具体时间、关联的 API 访问特征等。

---

## 4. 特别声明

SupaStore 仅作为请求的中介通道进行内存级转发，不承担最终用户生成内容的著作权归属及侵权直接法律责任。但我们鼓励健康绿色的 AI 产业生态，将积极配合版权方和监管部门维护知识产权和数据合规。
