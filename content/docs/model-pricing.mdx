SupaStore 以统一的 OpenAI 兼容接口聚合主流大模型。您只需要使用同一个 `Base URL` 与 API Key，即可在不同客户端或 SDK 中切换模型。

> [!NOTE]
> 实际可用模型、价格倍率与账户限额可能会随上游供应商和套餐变化调整。以 [控制台充值中心](https://supastore.cc/console/topup) 与 `/v1/models` 接口返回结果为准。

## 扣费与余额规则

- **按实际模型消耗计费**：请求完成后，根据输入 Token、输出 Token 与所选模型价格计算扣费。
- **流式响应同样计费**：`stream: true` 只改变返回方式，不改变 Token 统计规则。
- **失败请求通常不扣输出费用**：鉴权失败、参数错误、余额不足等请求不会产生模型输出 Token。
- **长上下文会显著增加成本**：AI 编程工具会自动携带代码片段、文件摘要和历史消息，建议定期压缩上下文。
- **不同模型价格不同**：高性能推理模型通常更贵，轻量模型更适合批处理和高频调用。

## 查询账户可用模型

您可以通过 `/v1/models` 获取当前账户可用模型列表：

```bash
curl "https://api.supastore.cc/v1/models" \
  -H "Authorization: Bearer YOUR_SUPASTORE_API_KEY"
```

返回结果中的 `id` 字段就是调用接口时传入的 `model` 值。

```json
{
  "object": "list",
  "data": [
    {
      "id": "gpt-4o",
      "object": "model",
      "owned_by": "openai"
    }
  ]
}
```

## 常见问题

### 为什么同一个工具每次消耗不同？

Cursor、Claude Code、Cline 这类 Agent 工具会根据当前任务自动携带上下文、文件内容和历史消息。上下文越长，输入 Token 越多，单次请求成本也会更高。

### 应该给每个工具创建不同 API Key 吗？

建议这样做。为 Cursor、Claude Code、Web UI、自研服务分别创建独立 API Key，可以更容易排查消耗来源，也方便单独撤销或限流。

### 如何降低成本？

优先使用轻量模型处理分类、摘要、格式转换等简单任务；只在复杂编程、推理或关键生成环节切换到高性能模型。
