SupaStore 支持获取当前所有可用的 AI 模型列表。系统会根据您使用的鉴权 Header 自动输出对应服务商的兼容格式。

### 📡 接口信息

* **请求方式**: `GET`
* **接口路径**: `/v1/models`

---

## 🔑 兼容性 Header 特性

为了让您能够零成本对接各种官方原生 SDK，SupaStore 实现了智能协议适配：
- **OpenAI 兼容模式**: 发送标准的 `Authorization: Bearer YOUR_API_KEY`，返回标准的 OpenAI 格式模型列表。
- **Anthropic 兼容模式**: 如果您在客户端直接配置 `x-api-key` header，网关将自动转换为 Anthropic 官方协议。
- **Gemini 兼容模式**: 支持在客户端注入 `x-goog-api-key` header 以适配 Google AI Studio 原生 SDK。

---

## 💻 调用示例 (cURL)

```bash
curl -X GET "https://supastore.cc/v1/models" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
