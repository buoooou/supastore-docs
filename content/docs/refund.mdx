感谢您选择 **SupaStore**。我们致力于为您提供高速、稳定的大模型 API 转发服务。如果您在充值后由于技术兼容性或接口体验问题需要退款，请参照以下政策申请。

---

## 1. 退款期限

- **充值余额退款**：自充值交易成功之日起 **7 天** 内，且未消耗该次充值额度，可申请退款。
- **活动/特殊赠送余额**：由于赠送额度（如新手注册赠送、活动返利赠送等）并非现金充值，因此赠送部分的余额不支持提现或退款。

---

## 2. 退款条件

为了防止欺诈、恶意透支和退款套利，退款申请须符合以下条件：
- 该笔订单对应的充值金额尚未在 API 调用中被消耗（或仅消耗了极少部分，如小于充值金额的 1% 且绝对值小于 1 元，核退时将扣除相应已消耗额度）。
- 账户未因违反 [服务条款](/terms) 或 [使用守则](/aup)（如恶意刷量、生成非法政治/色情内容被系统自动拦截并封禁）而被限制访问。
- 充值订单非通过外部非法代理商或第三方个人转卖获得。

---

## 3. 退款金额与通道手续费

- **退款手续费**：由于第三方支付通道（如支付宝、微信支付、USDT 等）会收取交易手续费，退款金额将扣除交易总额的 **5%** 作为通道处理服务费。
- **原路返回**：退款将一律原路返还至您充值时所使用的支付宝或加密货币（USDT）钱包。

---

## 4. 退款流程

1. 登录 [SupaStore 控制台](https://supastore.cc/console)，提交支持工单（Ticket），或发邮件至客服团队：[support@supastore.cc](mailto:support@supastore.cc)。
2. 工单/邮件标题请注明：**【申请退款】+ 您的注册邮箱 + 充值订单号**。
3. 客服与财务团队将在 **1-3 个工作日** 内完成额度核对、扣减并处理退款。
4. 资金到账时间取决于支付通道及您的发卡行，通常在 24-72 小时内到账。

---

## 5. 加密货币 (USDT) 充值退款特别说明

- **汇率标准**：若您使用 USDT 充值，由于加密货币的价格波动，退款时将按申请当日的即时汇率，扣除通道费和 Gas 费后，退还对应等值的 USDT 到您的原付款钱包地址。
- **网络手续费**：USDT 转账产生的区块链 Gas Fee（如 TRC-20 链的手续费）需由用户自行承担。
