## 1. 接受条款

一旦您注册账户、访问或使用我们的服务（包括但不限于 API 接口、用户控制台），即表示您已阅读、理解并同意接受本条款及我们的隐私政策的约束。如果您不同意本条款的任何内容，请立即停止使用本服务。

---

## 2. 服务说明

SupaStore 提供全球领先的 AI 大模型 API 中转转发与汇聚服务（兼容 OpenAI、Anthropic Claude、Google Gemini 等多种 API 格式）。我们致力于提供稳定、高速、高性价比的 API 转发能力，但由于大模型上游服务商（如 OpenAI、Anthropic 等）及网络传输环境的复杂性，我们不保证：
- 服务始终无中断、100% 及时或无任何运行错误。
- 上游模型对于特定 Prompt 的输出完全符合您的预期。
- 某些特定长思考或推理模型（如 o1/o3-mini/R1）的耗时在所有时间段都完全一致。

## 3. 账户管理与安全

- **账户唯一性**：账户仅限注册者本人或其团队（如组织机构）内部使用，严禁对外租借、转售或分享您的 API Key 给不相干的第三方。一旦发现异常的多地域高并发共享或恶意盗刷行为，本站有权在不通知的情况下限制或封禁账户。
- **信息准确性**：您必须提供真实、准确的注册邮箱，以便我们发送账单、服务通知和安全提醒。
- **密钥安全**：您负责妥善保管您的 API Key。因您自身原因（如代码上传至公共 GitHub 仓库、配置在安全性不足的第三方客户端）泄露 API Key 导致的额度损耗，本站概不负责。

---

## 4. 可接受的使用政策 (AUP)

您同意在使用本服务时，必须遵守您所在地法律法规以及 AI 生成内容合规要求。严禁使用本服务从事以下活动：
- **非法生成内容**：利用大模型生成违法、暴力、涉黄、政治敏感、欺诈、谣言或侵犯他人隐私的内容。
- **恶意扫描与攻击**：利用 API 对其他系统发起渗透测试、弱口令爆破或大规模漏洞扫描。
- **服务滥用**：通过技术手段恶意注册大量账户以获取新手赠送额度，或者以超出正常业务合理范围的恶意高并发请求冲击本站网关。

---

## 5. 额度充值与结算

- **计费规则**：根据您调用的模型 ID 及 Token 消耗量，从您的账户余额中扣除相应费用。各模型的实时费率请在 [控制台模型价格页](https://supastore.cc/pricing) 查看。
- **余额有效期**：除非有特定赠送额度说明，否则您充值的现金余额永久有效。
- **退款政策**：退款申请需遵守我们的 [退款政策](/refund)。通常情况下，已消耗的 API 额度不予退还。
