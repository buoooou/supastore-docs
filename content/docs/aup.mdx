本可接受使用政策（下称“AUP”）旨在指导用户如何合法、合规且负责任地使用 **SupaStore** 大模型 API 服务。所有用户在调用接口或部署应用时，均须遵守本守则。

---

## 1. 合规与法律红线

您在使用本服务进行 AI 交互、文本/图像/音视频生成或数据处理时，严禁用于以下违法或违规目的：
- **非法言论与敏感政治**：严禁诱导或生成涉及危害国家安全、散布政治谣言、扰乱社会秩序的违法内容。
- **涉黄与低俗**：严禁生成任何儿童色情（CSAM）、淫秽色情以及带有严重性暗示的敏感内容。
- **暴恐与自残**：严禁编写、优化或诱导生成关于枪支弹药制造、自杀自残指南、恐怖袭击策划等高度危险性的文本或指令。
- **知识产权侵权**：严禁利用 API 进行大规模的数据爬取、清洗，用以训练侵犯他人版权的竞品模型。

---

## 2. API 网关安全与滥用预防

为了保障平台所有开发者能够获得稳定的响应延迟，严禁进行以下破坏网关秩序的行为：
- **恶意刷号与刷额度**：禁止通过自动化脚本批量注册空壳账号以套取新手免费测试额度。
- **超限并发攻击**：禁止在未经官方报备并提升限速阈值的情况下，使用极其庞大的并发线程恶意冲击接口网关。
- **逆向与漏洞探测**：禁止对 SupaStore API 网关进行渗透扫描、越权漏洞测试或逆向网关防刷机制。

---

## 3. 违规处理机制

SupaStore 的系统会配合上游安全引擎，对请求进行自动化的内容合规与流量检测。若发现违规行为，我们将视严重程度采取以下措施：
1. **API 返回拦截**：如果 Prompt 触发合规敏感词，接口将直接返回 400 错误码并拦截该次请求。
2. **警示提醒**：针对偶发的轻微触发，我们将通过控制台或邮件发出合规提醒。
3. **账户临时冻结**：针对异常流量或疑似刷量行为进行临时限制，要求配合核实。
4. **永久注销且不予退款**：针对故意诱导生成非法内容、恶意攻击网关等严重违规行为，我们将直接封禁账户并清理 API 密钥。

---

## 4. 举报与反馈

如果您发现我们的接口被用于不正当的生成活动，或发现平台有其他安全隐患，请向我们反馈：[security@supastore.cc](mailto:security@supastore.cc)
